# Материалы в сообществе

Публикуется учебный пакет: исходная лекция, конспект, картинки и готовый тест,
если он создан. Без теста пакет тоже можно публиковать.

Владелец нажимает «Поделиться материалом» в меню лекции и подтверждает публикацию.
Все материалы изначально закрыты. Старые публикации отдельных тестов не открывают
файлы автоматически. Имя автора видно в сообществе, email не показывается.

Другой пользователь может читать конспект, скачать лекцию, пройти тест
или нажать «Сохранить в мою библиотеку». При сохранении копируются файл,
картинки, конспект, вопросы и варианты ответов. У копии новые идентификаторы
и отдельные файлы в MinIO. Она не публикуется автоматически.
Чужие результаты не копируются. Повторное сохранение открывает существующую копию.

«Сохранить доступ» добавляет последний готовый тест. При снятии публикации
закрывается доступ к оригиналу в сообществе. Уже импортированные копии и
сохранённые попытки остаются у участников. Изменения оригинала не меняют копии.

## API пакетов

Все запросы требуют входа в аккаунт.

| Метод | Адрес без `/api/v1` | Назначение |
|---|---|---|
| GET, PATCH | `/materials/{id}/publication` | Статус публикации и изменение своего пакета |
| GET | `/public-materials` | Список пакетов, `page` и `page_size` |
| GET | `/public-materials/{id}` | Конспект и сведения о пакете |
| GET | `/public-materials/{id}/download` | Исходная лекция |
| GET | `/public-materials/{id}/images/{order}` | Изображение конспекта |
| POST | `/public-materials/{id}/import` | Импорт в свою библиотеку |

В публикацию передаются `is_public` и `title`. Импорт возвращает `material_id`
и `imported`: новая копия получает HTTP 201, уже существующая HTTP 200.
Своему владельцу импорт возвращает исходный материал.

## Тесты и история

Вопросы и прохождение доступны через `/public-quizzes/{id}` и
`/public-quizzes/{id}/submit`. До завершения правильные ответы не раскрываются.
Попытки находятся в `/public-quizzes/attempts` и `/public-quizzes/attempts/{id}`.
Участник видит только свои ответы и результаты. Автор не получает к ним доступ.

Результат сохраняется как копия вопросов и ответов, учитывается в статистике
и недавней активности. Он остаётся доступным после удаления источника.

Старые `/quizzes/{id}/publication` и `/public-quizzes` сохранены для совместимости
с отдельными публикациями тестов. Через интерфейс теперь публикуются пакеты.

## Проверка

```bash
docker compose exec api alembic upgrade head
docker compose exec -T -e RUN_LOCAL_API_TESTS=1 api python -m unittest tests.integration.test_public_materials -v
docker compose exec -T -e RUN_LOCAL_API_TESTS=1 api python -m unittest tests.integration.test_public_quizzes -v
```

Проверяются доступ, реальные файлы и картинки, независимость копии, одновременные
повторные импорты, ошибка копирования, публикация без теста и история участников.
Проверки используют временные аккаунты и очищают свои данные.


## Тренировки и рейтинг

Сохранять копию необязательно. В опубликованном пакете можно читать лекцию
и конспект, а во вкладке теста нажать «Начать тренировку».
До старта показывается предупреждение: имя, процент и время будут видны
в рейтинге. Подробные ответы остаются закрытыми. Старые попытки не публикуются.

Время считает сервер. Закрытие, обновление страницы или уход с неё прерывает
незавершённую тренировку. Новый старт всегда создаёт новую попытку.
При обрыве соединения сервер убирает активную попытку после двух минут
без сигнала от страницы. Прерванные попытки не сохраняются в рейтинг.

В рейтинге показана одна лучшая попытка каждого участника: сначала процент,
потом меньшее время, затем более раннее завершение. Можно тренироваться повторно.
Это учебный рейтинг: он не ограничивает подготовку по лекции или запоминание
ответов, поэтому не заменяет защищённый экзамен.

| Метод | Адрес без `/api/v1` | Назначение |
|---|---|---|
| POST | `/public-quizzes/{id}/start` | Начать новую тренировку |
| POST | `/public-quizzes/{id}/cancel` | Прервать попытку по `run_id` |
| POST | `/public-quizzes/{id}/heartbeat` | Подтвердить активность страницы |
| GET | `/public-quizzes/{id}/leaderboard` | Первые 20 участников и своё место |

В отправку ответов добавляется `run_id`, полученный при старте.
Клиент не задаёт время прохождения. Повторная отправка того же `run_id`
возвращает сохранённый результат. Запрос без `run_id` сохраняет обычную
закрытую попытку, не участвующую в рейтинге.

```bash
docker compose exec -T -e RUN_LOCAL_API_TESTS=1 api python -m unittest tests.integration.test_training_ranking -v
```

## Ограниченный доступ

В окне «Поделиться материалом» можно выбрать всех пользователей, доступ по ссылке
или выбранные группы. Закрытый пакет показывается в сообществе только владельцу
и людям с доступом. Все его части, импорт, тест и рейтинг используют одну проверку.
Старый API публикации отдельных тестов тоже учитывает ограничения материала.

Группы создаются, меняются и удаляются в этом окне. Участники задаются по email,
можно добавить человека до регистрации. Адрес должен совпадать с его аккаунтом.
Изменение состава группы сразу действует для всех её материалов.

Ссылка содержит случайный секрет во фрагменте `#share=...`. После входа страница
передаёт его в заголовке `X-Material-Share` при GET пакета и убирает из адресной строки.
Сервер сохраняет доступ для этого аккаунта. Секрет не попадает в URL API и обычные
журналы запросов. Пересланная ссылка даст доступ любому вошедшему получателю.
Для конкретных людей следует использовать группы.

«Заменить ссылку» отзывает старую ссылку и доступ, выданный по ней.
«Закрыть доступ» отключает оригинал. Скачанные файлы, импортированные копии
и личная история попыток у получателей сохраняются.

PATCH публикации принимает `visibility`: `public`, `link` или `groups`,
`group_ids` и необязательный `rotate_link`. Без `visibility` режим сохраняется.
GET/POST `/sharing-groups` и PUT/DELETE `/sharing-groups/{id}` доступны только
владельцу группы. В чужих ответах нет состава группы или секрета ссылки.

```bash
docker compose exec -T -e RUN_LOCAL_API_TESTS=1 api python -m unittest tests.integration.test_material_sharing -v
```

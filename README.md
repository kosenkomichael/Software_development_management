# Software_development_management
5-й курс, менеджмент разработки ПО

[Схема базы данных](docs/database-schema.md) с полями и связями таблиц.

Восстановление пароля: запустите `docker compose --profile mail up -d mailpit`.
Локальные письма открываются на http://localhost:8025. Нажмите «Забыли пароль?»
в форме входа и укажите email аккаунта. Ссылка из письма действует 30 минут.
Для настоящей почты задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`,
`SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_STARTTLS` и `FRONTEND_URL` в `.env`.
После смены пароля нужно войти заново на всех устройствах.

История прохождений открывается по кнопке под тестом. Там можно открыть прошлую попытку
и посмотреть свои ответы. История сохраняется с момента добавления этой функции.
После обновления проекта примените миграции: `docker compose exec api alembic upgrade head`.

В меню материала доступны переименование, избранное и удаление из библиотеки.
Избранные лекции находятся в разделе «Избранное». Удаление закрывает доступ
к материалу через сайт, но пока сохраняет строки в базе и файлы в MinIO.

После загрузки автоматически создаётся только конспект. Страницу можно закрыть:
обработка продолжится на сервере. Готовый конспект сразу доступен для чтения.
Чтобы создать тест, откройте вкладку «Тест» и нажмите «Создать тест».

В личном кабинете можно изменить имя, фамилию, email и пароль.
Для смены email или пароля нужно ввести текущий пароль. Другие сессии
после этого завершаются, текущий вход сохраняется.

В меню готового материала есть «Опубликовать материал». В сообществе будут
доступны лекция, конспект и готовый тест, если он есть. Пользователь может
читать материал, пройти тест или сохранить независимую копию в свою библиотеку.
Результаты доступны участнику во вкладке «Мои прохождения», статистике и активности.
Подробности: [публичные тесты](docs/public-tests.md).

Публичный тест можно проходить без импорта: «Начать тренировку» запускает
серверный таймер. В «Рейтинге тренировок» сравниваются лучшие попытки участников
по проценту и времени. Подробные ответы остаются личными.
